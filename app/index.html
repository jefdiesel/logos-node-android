Updates

Installed version: -

Your PIN: 6 to 12 digits.

Updates come with a new version of the Android app.

Updates come from the project's GitHub repository, github.com/jefdiesel/logos-node-android: its release branch, which only gets versions that passed every test. The app checks each file against the release list before using it. The node keeps running.

Back up

Saves this wallet as an encrypted file. The file is locked with a backup password you choose here, not your PIN. Use a long one you won't forget.

A short password is easier to guess if someone gets this file. 12 or more characters, or four random words, is safer.

Your PIN: 6 to 12 digits.

Saved to Downloads.

  • Move it somewhere safe off this phone.
  • Anyone with the file and its password controls this wallet.
  • If you lose the password, the backup can't be opened. It can't be recovered.

Restore from a backup

Restoring replaces this wallet's accounts with the ones in a backup file. Coins on the accounts it replaces can then only be reached through a backup of them.

Your PIN: 6 to 12 digits.

The app talks to the node on this device, and reaches out to two places: the project's GitHub repository, to check for updates, and the LNS name service, to look names up.
