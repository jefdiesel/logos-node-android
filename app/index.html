Back up wallet

Saves this node's keys as an encrypted file. The file is locked with a backup password you choose here, not your PIN. Use a long one you won't forget.

A short password is easier to guess if someone gets this file. 12 or more characters, or four random words, is safer.

Your PIN: 6 to 12 digits.

Saved to Downloads.

  • Move it somewhere safe off this phone.
  • Anyone with the file and its password controls this wallet.
  • If you lose the password, the backup can't be opened. It can't be recovered.

Restore from a backup file

Restoring replaces this wallet's keys with the keys in a backup file. Coins on the keys it replaces can then only be reached through a backup of those keys.
