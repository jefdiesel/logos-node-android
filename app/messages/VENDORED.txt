These are the versions the names project pins (gateway/app-src/package-lock.json). To update: take the new
msg-crypto.js from the names project, the matching npm tarballs (check each against the lockfile's
integrity), apply the same import-path changes, run tests/msg_test.mjs, and `python3 tools/release.py write`.
